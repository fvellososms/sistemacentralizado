# Logos das empresas clientes

A logo do cabeçalho do checklist de equipamentos vem desta pasta. Ela é escolhida pela
empresa cliente vinculada à obra (Administração > Obras).

**Nome do arquivo:** o nome da empresa em minúsculas, sem acentos e com hífen no lugar de espaços.
**Formatos aceitos:** PNG ou JPG.

| Empresa        | Arquivo              |
| -------------- | -------------------- |
| PETMAX         | `petmax.png`         |
| Hotel Marina   | `hotel-marina.png`   |
| Grupo CTV      | `grupo-ctv.png`      |
| Tetris         | `tetris.png`         |
| SUM Engenharia | `sum-engenharia.png` |
| LSMG           | `lsmg.png`           |
| Origem ATTO    | `origem-atto.png`    |
| ENGEPAR        | `engepar.png`        |
| ECO Solution   | `eco-solution.png`   |

Obra sem empresa vinculada, ou empresa sem arquivo aqui, sai com a logo da FVelloso.
Depois de adicionar uma logo é preciso publicar o site de novo.
